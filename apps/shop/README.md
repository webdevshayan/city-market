# shop (shop dashboard)

Flutter app for shop owners: catalogue management, incoming orders, and the
monthly **Ujrah commission statement** generated from the fixed tier schedule
in `server/finance` (0–50 orders 0%, 51–200 5%, 201–500 7%, 501+ 9% capped at
7000).

Run (once the Flutter SDK is available): `flutter run` from this directory.
Full implementation lands in Phase 4.
